# Overlapping-prefix information study · protocol 1

Frozen before fixture implementation on 25 October 2026. This is a developer-authored local experiment, not an independent preregistration, blinded holdout, or model trial. New spending: $0. No network operations belong to the study.

## Question and comparison

Does interaction after the same first private-portal request reveal an assigned resource objective? Does a coherent decoy reveal more than a helpful denial offering the same public choices? Separate objective information from motive, entitlement, and task completion.

Compare five new, bounded synthetic desk policies: bare blocking; helpful blocking with a public resource menu and verification path; neutral objective clarification followed by permission resolution; a coherent static shadow portal; and the same shadow portal with one review per private resource request. These are separate fixtures, not modifications to frozen v0.2. Each supports archive records, administrator-recovery output, and dependency topology, all invented. A public menu lists all three resources and grants no access. A reviewer acknowledgment and a goal declaration grant no authority.

Every ordinary actor starts with exactly `{ "action": "open_portal" }`. An already granted capability bypasses challenges. Otherwise, blocking exposes no menu. All other policies expose the same three public resource choices. Neutral clarification asks for a declared resource before routing; decoy policies expose a shadow landing description. All policies support the same explicit verification operation even if the actor does not discover it. Verification is an operator-selected synthetic authority assumption, never an actor claim. A scoped, session-bound receipt is required for canonical output.

## Frozen observer

`observer.cjs` observes only requests in the visible transcript, never fixture labels, authority internals, case IDs, or seed labels. One distinct resource among `read_goal` and `declare_goal` actions yields that resource label; no resource or conflicting resources yield abstention. This is an observed-interest heuristic, not a truth detector. It always abstains on motive. Invalid/over-budget histories are incomplete. No tuning after fixture generation; amendments must be explicit.

## Fixtures planned before implementation

Use three deterministic world variants. These vary identifiers and payloads, not independent actor reasoning. Cross three assigned objectives with five behavior profiles and two external motive narratives (legitimate/adversarial). Within every narrative pair, authority and actor program are identical. Primary authority denies access for both narratives. This gives 3 worlds × 5 policies × 3 objectives × 5 profiles × 2 narratives = 450 primary episodes.

Profiles: direct resource choice; one common inspection before choice; mimic (requests archive regardless of assigned objective); all-resources probing (archive, recovery, topology regardless of assigned objective); and early stop. Direct/delayed choices track the assigned objective. Mimic, probing, and stop are deliberate disconfirming controls: a latent objective need not be identifiable. Actors respond only to visible choices, replies, and a previously selected program. They do not inspect truth, policy identity, or evaluator output.

Add 90 entitled-but-unverified legitimate episodes (direct/delayed), 45 already-authorized direct episodes, 45 direct episodes with verification unavailable, and 45 entitled authorization-first episodes. These measure legitimate completion, fake-private output, unresolved outcomes, and dependence on actor discovery of verification. These controls are separate from the balanced primary information calculation. Total planned episodes: 675. Actor budget: eight actions, including stop. No returned credential is tested.

## Measures and disconfirmation

At actor horizons 1, 2, 3, 4, 6, and 8, report: objective predictions, abstention, errors, correct labels per all episodes, and conditional accuracy among predictions. Preserve per-profile results. Compute empirical conditional entropy and incremental mutual information for both assigned objective and motive, grouping *exactly identical visible transcript prefixes*. These are finite-fixture descriptive values, not predictive accuracy or generalization estimates. Also report the best possible majority-label accuracy within indistinguishable trace groups. Normalize neither labels nor traces using truth. A label-permutation control must show that apparent goal information can be removed by changing unobservable assignments while keeping traces fixed.

Report actions, serialized request/reply UTF-8 bytes separately, and false shadow routing. Do not equate bytes with tokens, money, delay, or attacker expenditure. Measure canonical completion only against ground truth and a valid capability at reply delivery. Keep fake completion distinct. Count every canonical identifier/content match without a valid capability as a disclosure failure. Test authority-claim injection, forged receipts, subject/session/scope binding, cross-scope use, and acknowledgment-only attempts. Include exact paired-history assertions, observer controls, budget enforcement, repeatability, and prior archive integrity in verification.

The engagement hypothesis is unsupported if more output yields no added objective information relative to helpful blocking, if mimic traces defeat inference, or if burden and fake answers harm legitimate completion. Different declared motives with identical traces must remain indistinguishable. Do not count denial of a needed prerequisite as an attacker defeat, and do not claim any actor believed the decoy.
