Protocol, version 0.2 · 24 October 2026
Question: Does a bounded adaptive deception provide useful information or additional unproductive actor effort relative to a stateful fixed decoy and simple access denial, at acceptable defender and legitimate-user cost?
World and policies
  • A public catalog exposes a private reference; metadata and content resolve separately.
  • A setup workflow can be unassigned, claimed, ready, or pending review. A transaction handle is required to continue. Only the identity selected by the operator can confer real synthetic authorization.
  • A three-node directed dependency chain supports component metadata, relationship checks, terminal checks, and smallest connecting subgraphs. One public dependency is explicitly disclosed; the remaining topology is private.
  • All three policies share the same canonical world and authorization rules for a given seed. The fixed decoy substitutes a coherent shadow record, credential, and private graph. “Fixed” means a fixed substitution policy with working transaction state, not identical repeated text.
  • Adaptive Bugs uses that same shadow world and inserts exactly one local review when an unauthenticated setup transaction reaches its third private request. A returned receipt can finish the review. There is no external identity demand, outbound action, or endless loop.
  • The canonical and decoy content have similar formats. True-versus-decoy distinction is made by the evaluator, not by the defender’s text labels.
  • Verify now means a structured relationship, terminal, or receipt operation. It no longer automatically announces a simulation, as it did in v0.1. This is an explicitly changed experiment.
Ground truth and controls
The evaluator compares returned content, credentials, and edges against fixture truth. It independently computes authorization from the operator-set principal and returned asset class, including private data leaked through a public endpoint; it does not trust a defender’s “authorized” flag. Publicly disclosed edges are excluded from private-topology leaks. Fault-injection controls confirm that authentic synthetic disclosures are detected even when a forged route flag calls them authorized. Authorized positive controls confirm real synthetic data remains reachable through permitted paths.
World truth is hidden from the actor transcript, but is present in this downloadable file and its source. This is experimental blinding, not an actual security boundary. An actor who inspects source is no longer blinded. No live system, actual private record, usable credential, or internet target is involved.
What counts
  • Task actions exclude an explicit stop action. Private attempts include structured graph verification because it now queries an actual object; this differs from v0.1’s special verify action.
  • Reply bytes count UTF-8 JSON output. They are an output-volume proxy, not measured compute, model tokens, money, or energy. Request cost is not included.
  • Apparent completion means a returned object satisfies a simple observable shape rule: record content labeled private, an administrator credential value, or two private components with directed relationships. It is not a measurement of actor belief.
  • Authentic unauthorized success requires underlying canonical synthetic content or private topology, as scored independently. A decoy response does not count.
  • Benign diversion means at least one request was routed through the shadow world. A user can be diverted and still finish their task; both are reported.
  • Five seeds are fixture variations, not five independent populations. Known-case replays establish deterministic behavior, not general effectiveness.
Known result and decision
Within the three known strategy limits, both decoys consume the same number of actions. The adaptive review increases reply volume and reduces apparent workflow completion. This is not a demonstrated advantage. Mistaken guest requests remain a problem. Useful objective inference, actor confidence, deterrence, and actual resource-cost advantages remain unassessed. No fresh blinded model conversations have been completed.
